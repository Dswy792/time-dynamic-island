# 灵动岛 (Dynamic Island) · v5.2.1

**一个优雅、轻量、可自由定制的 Windows 顶部时间胶囊；微信 / QQ 新消息会变成胶囊旁的圆形副岛。**

纯 C++17 / Win32 / GDI+ 实现 · 单个 exe · 无 .NET / Java / 第三方框架依赖 · Windows 10 / 11 · 支持微信 / QQ 消息提醒

---

## 💡 开发动机

作为一个喜欢简洁桌面的用户，我有一些特殊的任务栏使用习惯：

- **隐藏任务栏**：让屏幕空间最大化
- **任务栏透明化**：使用工具让任务栏完全透明，达到"隐形"效果

但这些习惯带来了一个**痛点**：在某些特定场景下，我完全看不见时间了！

### 😫 遇到的问题

1. **全屏应用切换时**：从游戏或视频切出来，找不到时间在哪里
2. **透明任务栏失效时**：某些程序会让透明效果临时失效，任务栏变得突兀
3. **多显示器环境**：副屏的任务栏可能被遮挡或位置不习惯
4. **专注工作时**：隐藏任务栏可以减少干扰，但偶尔又需要快速瞥一眼时间
5. **消息分散注意力**：工作时不想频繁切到微信 / QQ，但又怕漏掉重要消息

### 💡 解决方案

我需要这样一个时间显示工具：

- ✅ **独立于任务栏**：不依赖任务栏存在
- ✅ **始终可见**：固定在屏幕顶部，不会被普通窗口遮挡
- ✅ **简洁美观**：要能融入桌面，而不是贴一块"补丁"
- ✅ **低存在感**：平时不引人注目，需要时一眼就能看到
- ✅ **低功耗**：空闲时几乎不占 CPU，内存占用要低
- ✅ **足够可定制**：时间格式、日期、主题、大小、位置、字体都能调
- ✅ **消息不打断（v5.2）**：新消息在灵动岛旁边弹出一枚圆形副岛，看一眼就知道来自谁

于是，**灵动岛 (Dynamic Island)** 应运而生。

### 🎯 设计理念

1. **胶囊形状**：现代、柔和的跑道圆角，不做生硬的矩形窗口
2. **小巧精致**：默认 Medium 150 × 28 DIP，只占屏幕顶部一小条
3. **聪明交互**：鼠标悬停平滑放大；不操作时安静地待着
4. **完整设置**：v5 重写了全部设置界面，所见即所得、实时预览
5. **反作弊友好**：纯外部 Win32 程序，不注入、不挂钩子（详见"反作弊系统兼容性说明"）
6. **消息不打扰**：圆形副岛 + 悬停才显示内容；默认常驻，点一下即收起，不打断当前工作

### 🆕 v5 做了什么

v4 的设置界面依赖 Win32 资源对话框，样式陈旧，也无法跟随深色主题和高 DPI。v5 是一次完整的重写：

- 窗口从"GDI 区域裁剪"改为**逐像素 alpha 的分层窗口**：圆角真正抗锯齿，还能画出柔和投影；
- 悬停放大、自动隐藏都改为**基于时间的缓动动画**，不再一帧一帧硬跳；
- 设置界面改为**全自绘窗口**：深/浅色主题、Per-Monitor DPI、实时预览卡、卡片式分组；
- 新增：不透明度、4 种日期格式、星期显示、AM/PM 后缀、全屏应用时隐藏、拖动自定义位置、托盘菜单；
- 全部源代码按 include/ + src/ 模块化拆分，并附带单文件编译检查脚本。

### 🆕 v5.1 做了什么

v5.1 是一次体验向的小版本更新，重点是设置窗口的流畅度与交互的一致性：

- **设置窗口更跟手**：重绘改为脏矩形 + 合并绘制，悬停 / 点击不再整窗重绘，拖动标题栏只移动窗口；悬停、点击、拖动都更流畅；
- **设置窗口更完整**：底部新增"退出程序"按钮（点击后二次确认再退出），行为卡片新增"系统时间设置"入口（打开 Windows 日期和时间设置）；
- **更顺手的交互**：左键单击灵动岛直接打开设置窗口（v5 是打开系统时间设置）；右键单击不再误触，托盘右键菜单保持不变；
- **新图标**：深色圆角底 + 白色胶囊 + 蓝色消息角标，16–256 px 多尺寸；
- **版本升级到 5.1.0**，注册表 schema 不变（`SettingsVersion` 仍为 2）。

### 🆕 v5.2 做了什么

v5.2 补上了"顺手看消息"这块拼图，并让设置界面更整齐：

- **微信 / QQ 消息提醒**：新消息会在灵动岛右侧弹出对应软件的圆形副岛；微信通过 Windows UI Automation 读取会话列表，QQ 通过 Windows 通知（toast）；
- **副岛保持整体居中**：出现 1～2 枚圆形副岛时，主胶囊会相应左移，整个组合的中点始终保持在原来的位置；
- **通知设置卡**：设置窗口新增"通知"卡片，可开关消息提醒、隐私模式、微信 / QQ 来源与停留时长；
- **设置窗口两侧对齐**：左右两列卡片等高（各 398 DIP），预览卡改用与真实灵动岛相同的渲染器按实际大小绘制，并标注"实际大小"；
- **版本升级到 5.2.0**，注册表新增 5 个通知相关值（`SettingsVersion` 仍为 2）。

### 🆕 v5.2.1 做了什么

v5.2.1 根据使用反馈调整了消息副岛的默认行为，并让圆形图标更精致：

- **副岛默认常驻**：新消息弹出的圆形副岛不再自动消失，会一直显示在灵动岛旁边，直到你点击它（打开微信 / QQ 窗口）、关闭"消息提醒"或关闭对应来源；
- **可选的自动收起**：仍可在设置里把"停留时长"设为 1–10 秒让副岛自动收起；设为 0（默认）时显示"常驻"；
- **应用 Logo 更小**：圆形副岛里的微信 / QQ 图标缩小到圆直径的约 62%，周围保留与胶囊一致的材质和描边；
- **版本升级到 5.2.1**，注册表项不变，`SettingsVersion` 仍为 2。

## ✨ 功能特性

### 🎨 外观与渲染

- 🖼️ **逐像素 Alpha 分层窗口**：胶囊边缘、阴影都由 GDI+ 绘制后经 UpdateLayeredWindow 提交，圆角真正平滑，没有锯齿或色边
- 🌫️ **柔和投影**：10 层同心圆角矩形叠加出自然的下沉阴影，深色壁纸上也不会"糊"成一块
- 🎨 **细微渐变 + 1px 描边**：垂直渐变让胶囊更有体积感，描边保证在相近颜色的壁纸上仍有边界
- 🎬 **平滑悬停展开**：170 ms EaseOutCubic 缓动放大到 1.08 倍
- 🛝 **平滑隐藏 / 显示**：260 ms EaseInOutCubic 缓动滑出/滑入屏幕顶部
- 📐 **Per-Monitor V2 DPI 感知**：4K / 125% / 150% / 多显示器混合缩放下依然清晰，尺寸按 DPI 等比缩放
- 🌓 **深色 / 浅色 / 系统（跟随 Windows）** 三套主题，实时响应 Windows 主题切换
- 🫥 **可调不透明度**：55% – 100%，让胶囊更"轻"地融入桌面
- 🔤 **字体自动适配**：内容过长时逐像素缩小字号，永不溢出胶囊
- 🪪 **v5.1 新图标**：深色圆角底 + 白色胶囊 + 蓝色消息角标，16–256 px 多尺寸，任务栏 / 托盘里都清晰可辨
- 🟢 **圆形消息副岛（v5.2，v5.2.1 起默认常驻）**：新消息时主胶囊右侧弹出圆形副岛（直径与胶囊高度一致），同一套柔和阴影 / 渐变 / 描边；圆内是微信 / QQ 的真实应用图标（从已安装程序的可执行文件提取，约为圆直径的 62%），周围保留材质与描边；最多两枚，整体中心保持不动

### 🔔 消息提醒（v5.2）

- 💬 **两种消息来源**：
  - **微信**：微信 4.x（Weixin.exe）不会把新消息交给 Windows 通知中心，因此通过 Windows UI Automation（系统无障碍 API，自动化 ID `session_list`）读取微信的会话列表，识别到新消息后显示副岛；不注入、不挂钩、不读内存，也不访问聊天数据库；
  - **QQ**：QQNT 不暴露可供读取的 UI 自动化树，因此改为读取 Windows 通知中心里的 QQ toast。
- 🟢 **圆形副岛**：微信 / QQ 各自对应一枚圆形副岛，出现在主胶囊右侧；圆内是真实应用图标（约 62% 直径，居中），最多同时存在两枚（微信在内、QQ 在外）。
- 🎯 **整体居中**：副岛出现时主胶囊按组合总宽度左移，让"主胶囊 + 副岛"这个整体的中点保持不动，视觉上不会跳动。
- 🖱️ **悬停看内容**：鼠标悬停某枚副岛，会在其下方显示一条胶囊状提示（"发送者：消息内容"）；开启隐私模式后只显示"微信 有新消息 / QQ 有新消息"。
- 👆 **点击打开应用**：点击副岛会把对应的微信 / QQ 窗口带到前台（最小化到托盘会先恢复），并收起该副岛。
- 📌 **默认常驻（v5.2.1）**：副岛会一直显示在灵动岛旁边，直到你点击它（打开应用并收起）、关闭"消息提醒"或关闭对应来源；同来源的新消息只会更新悬停提示的内容；
- ⏱️ **可选自动收起**：把停留时长设为 1–10 秒后，副岛会在对应秒数后自动收起（悬停时暂停计时，移开后继续）；设置为 0（默认）时显示"常驻"。
- 🛑 **不打断自动隐藏**：只要还有副岛在显示，灵动岛就不会自动隐藏。
- 🔒 **隐私**：消息内容只在内存中短暂存在；关闭"显示内容"后界面上不显示任何消息正文。

> 已知限制：微信需要保持客户端运行（最小化到托盘也可以），并且依赖微信界面暴露的无障碍树，微信大版本更新可能改变结构；只能看到会话列表里的最后一条预览，读不到历史消息，正在查看的会话不会提醒。QQ 需要在自己设置里开启新消息通知，并在 Windows 设置里允许 QQ 通知，否则收不到 toast。

## 🚀 快速开始

### 🧰 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10（1809+）/ Windows 11 |
| 编译器 | Visual Studio 2019 / 2022，勾选"使用 C++ 的桌面开发"（MSVC x64 + Windows SDK） |
| Windows SDK | 10.0.17763 及以上（提供 C++/WinRT 头文件，用于读取 Windows 通知；安装 VS 的 C++ 桌面开发工作负载即可） |
| 其他依赖 | 无第三方库。GDI+、Shell API、UI Automation 均由 Windows 提供；C++/WinRT 头文件来自 Windows SDK |
| 运行时 | 无 .NET / Java 要求；使用 MSVC 默认动态运行库，目标机需具备 Visual C++ 2015–2022 运行库（多数系统已随其他软件安装） |

### 🔨 编译

1. 打开 PowerShell，进入项目目录：

   ```powershell
   cd "D:\Trae CN\Code\灵动岛"
   ```

2. 运行构建脚本：

   ```powershell
   .\build.ps1
   ```

3. 看到下面的输出即表示成功：

   ```text
   ========================================
     SUCCESS! Created: DynamicIsland.exe
   ========================================
   ```

   构建产物为项目根目录下的 **DynamicIsland.exe**；中间文件在 builds/ 中（可随时删除）。

build.ps1 会自动通过 vswhere.exe 找到最新的 Visual Studio、调用 vcvarsall.bat x64 配置环境、编译资源（图标 / manifest / 版本信息）、编译全部 src/*.cpp 并链接。若环境不完整，脚本会给出对应的错误提示。

### ▶️ 运行

```powershell
.\DynamicIsland.exe
```

程序启动后会在屏幕顶部出现时间胶囊，并在系统托盘显示图标。开机自启默认关闭，可在设置窗口或托盘菜单中打开。

开发时想直接打开设置窗口，可以用：

```powershell
.\DynamicIsland.exe --settings
```

### 🗑️ 卸载 / 清理

```powershell
.\clean.ps1
```

脚本会依次：结束正在运行的进程 → 删除 DynamicIsland.exe、builds/ 及各类中间产物 → 删除 HKCU\SOFTWARE\DynamicIsland 设置 → 删除 Run 键中的自启项。脚本已固定在项目目录内操作，不会删除工作区之外的文件。

> 说明：clean.ps1 会删除项目目录下的 *.obj / *.lib / *.exp 等编译中间文件，请确认项目目录中没有其他需要保留的构建产物。

## 🖥️ 系统要求

- **操作系统**：Windows 10 1809 及以上 / Windows 11（建议保持系统更新）
- **显示器**：单屏 / 多屏均可；主屏顶部用于预设位置，自定义位置可拖到任意显示器工作区
- **缩放**：支持 Windows 的 Per-Monitor 缩放（100% / 125% / 150% / 200% / 自定义）
- **内存**：常驻内存为个位数 MB 级别（取决于系统与位图缓存，以任务管理器实测为准），空闲时 CPU 接近 0
- **磁盘**：一个可执行文件，无额外数据文件
- **权限**：普通用户权限运行（manifest 为 asInvoker），不需要管理员
- **微信提醒**：微信 4.x 客户端需保持运行（最小化到托盘可以），程序通过 Windows UI Automation 读取其会话列表
- **QQ 提醒**：需要在 QQ 自己的设置中开启新消息通知，并在 Windows 设置中允许 QQ 通知（QQ 不发系统通知时收不到提醒）
- **通知访问**：QQ toast 通道需要允许本程序访问通知；设置窗口的"通知"卡片会显示授权状态并可一键授权

## 🎯 使用说明

### 🪟 打开设置

以下任一方式都可以打开设置窗口：

1. **左键单击灵动岛**（v5.1 起；右键不再打开设置）
2. **左键单击或双击托盘图标**
3. **托盘图标右键 → 设置(灵动岛)...**
4. **再次运行 DynamicIsland.exe**（单实例会把设置窗口带到前台）
5. 命令行加 --settings 启动

### 🧩 设置窗口

设置窗口与灵动岛使用同一套视觉语言（GDI+ 分层自绘，无原生控件），窗口居中对齐工作区（600 × 758 DIP，150% 缩放下为 900 × 1137 像素），打开后会**实时预览**当前改动：

- **顶部**：标题"灵动岛设置"、副标题（Dynamic Island 版本号）、圆形关闭按钮；拖动标题栏可以移动窗口（会被限制在工作区内）
- **预览卡（预览）**：直接用与真实灵动岛相同的渲染器绘制，阴影、渐变、描边、不透明度和文字排版都与桌面上的胶囊一致，并按实际大小显示，右上角标注"实际大小"；预览会随时间更新，文本没变化时不重绘
- **左列**（卡片总高 398 DIP，与右列底部对齐）：
  - **时钟**（150 DIP）：24 小时制、显示秒数、显示上/下午（24 小时制下置灰不可点）
  - **外观**（236 DIP）：主题（深色 / 浅色 / 系统）、尺寸（小 / 中 / 大）、字号（− / +，9 – 32）、粗体、不透明度（− / +，55% – 100%，步进 5%）
- **右列**（卡片总高 398 DIP）：
  - **日期**（170 DIP）：显示日期、显示年份、显示星期，以及 4 个日期格式胶囊——胶囊上直接显示该格式的示例日期（如 10/28、28/10、2026-10-28、10月28日）
  - **行为**（216 DIP）：自动隐藏、隐藏延迟（− / +，步进 5 秒）、全屏时隐藏、开机自启、位置（左 / 中 / 右）、"重置位置"和"系统时间设置"两个文字按钮
- **通知**（v5.2，整行宽度）：消息提醒、显示内容、微信、QQ 四个开关 + 停留时长步进（0–10 秒，0 时显示"常驻"）+ "微信读取界面、QQ 走系统通知；不注入、不读内存"提示；未获得通知访问授权时，卡片底部显示"未授权通知访问 · 点击授权"
- **底部**：左侧"退出程序"（红色危险按钮，点击后会二次确认再退出）、提示"Enter 确定 · Esc 取消" + 取消 / 应用 / 确定 按钮

> v5.1 还重做了窗口的重绘方式（脏矩形 + 合并绘制），悬停、点击、拖动标题栏都更跟手，不再整窗重绘。

按钮行为：

| 按钮 / 按键 | 行为 |
| --- | --- |
| **应用** | 应用并保存当前修改，窗口保持打开 |
| **确定** | 应用并保存，关闭窗口 |
| **取消 / X / Esc** | 放弃本次未应用的修改并关闭 |
| **Enter** | 等同"确定" |
| **退出程序** | 弹出确认框，确认后退出灵动岛（设置窗口也会关闭） |

设置窗口是**非模态**的：打开时仍可操作托盘、拖动灵动岛。应用修改后，灵动岛、托盘提示会立即刷新。

> 注意：设置窗口里的配置修改（包括"开机自启""重置位置"）都是**待生效**状态，只有点击"应用/确定"后才会写入；"系统时间设置"是直接打开系统设置页。托盘菜单里的同类操作则是立即生效的。

### 🔔 消息提醒设置与使用

**设置窗口 → 通知**：

- **消息提醒**：总开关（默认开）。关闭后不再弹出任何副岛，下方"显示内容 / 微信 / QQ / 停留时长"会一并置灰。
- **显示内容**：默认开。关闭后进入隐私模式，悬停提示只显示"微信 有新消息 / QQ 有新消息"，不显示发送者和正文。
- **微信 / QQ**：分别控制两个来源。
- **停留时长**：0–10 秒，步进 1 秒。**0（默认）= 常驻**，副岛不会自动消失；1–10 秒 = 到时间后自动收起。
- **通知访问**：QQ 走 Windows 通知通道，若 Windows 尚未授权，卡片上会出现"未授权通知访问 · 点击授权"；点击后会弹出系统授权对话框，也可以到 Windows"设置 → 隐私和安全性 → 通知"里修改。

**副岛行为**：

- 新消息到达时，对应软件的圆形副岛从主胶囊右侧弹出（微信 / QQ 的真实应用图标，约占圆直径的 62%），最多同时两枚（微信在内、QQ 在外）；
- 副岛出现时主胶囊会左移，整个"胶囊 + 副岛"组合的中点保持不动；
- **默认常驻**：副岛会一直显示，直到你单击它、关闭"消息提醒"或关闭对应来源；同来源的新消息只会更新悬停提示里的内容；
- 鼠标悬停副岛：下方显示"发送者：消息内容"的胶囊提示；若设置了 1–10 秒自动收起，悬停会暂停收起计时，移开后继续；
- 单击副岛：把微信 / QQ 窗口带到前台（最小化到托盘会先恢复），并收起该副岛；
- 只要副岛还在显示，灵动岛就不会自动隐藏。

**前置条件与限制**：

- **微信**：需要微信 4.x 客户端保持运行；程序读取的是微信会话列表的无障碍文本（最后一条消息预览），读不到历史消息，正在查看的会话不会提醒；微信更新界面结构后可能需要适配。
- **QQ**：QQNT 不提供 UI 自动化树，只能依赖 Windows 通知；需要在 QQ 设置中开启新消息通知，并在 Windows 设置中允许 QQ 发送通知，且本程序获得通知访问权限。
- 消息内容只在内存中短暂保留，不会写入注册表或磁盘（程序不保存聊天记录）。

### 🕐 时间设置

- **24 小时制**：14:05:30 / 14:05
- **12 小时制**：小时补零为两位（00 点显示为 12），如 02:30:45 PM；是否显示 AM / PM 后缀由"AM/PM 后缀"开关控制
- **显示秒钟**：关闭后只显示 HH:MM
- AM/PM 后缀只在 12 小时制下有意义；切换回 24 小时制时该选项会变灰，但你的偏好会被保留
- 想打开 Windows 的"日期和时间"设置：设置窗口 → 行为 → **系统时间设置**，或托盘右键菜单 → **日期和时间设置**

### 📅 日期设置

- **显示日期** 关闭时，灵动岛只显示时间
- **显示年份** 对 MM/DD、DD/MM、中文格式生效；YMD 格式始终带年份
- **显示星期** 追加系统区域格式的短星期名；不同的 Windows 区域设置会显示不同语言
- 日期与时间之间会自动留两个空格
- 日期/时间文本都来自系统本地时间，与任务栏时钟一致

### 🎨 外观设置

**主题**：

| 主题 | 说明 |
| --- | --- |
| 深色（默认） | 深灰胶囊 + 亮色文字，适合深色壁纸 |
| 浅色 | 浅灰白胶囊 + 深色文字，适合浅色壁纸 |
| 系统 | 读取 Windows"个性化 → 颜色"的应用模式，实时跟随 |

**尺寸**（DIP，96 DPI 基准；悬停时 ×1.08）：

| 尺寸（设置里显示为） | 胶囊尺寸（DIP） | 说明 |
| --- | --- | --- |
| 小（Small） | 120 × 24 | 最紧凑 |
| 中（Medium，默认） | 150 × 28 | 日常推荐 |
| 大（Large） | 180 × 32 | 大字体 / 大屏 |

**字体**：

- 字号 9 – 32（默认 14），粗体开关默认开启
- 字体优先使用 Microsoft YaHei UI，缺失时回退 Segoe UI / Arial
- 内容超出胶囊的宽或高时会自动逐像素缩小字号，保证不溢出

**不透明度**：

- 范围 55% – 100%（步进 5%），默认 100%
- 控制的是胶囊填充的透明度；文字与阴影保持清晰，因此在低透明度下文字依然可读

### 🫥 行为设置

**自动隐藏**：

- 开启后，鼠标离开灵动岛区域一段时间（隐藏延迟，0 – 3600 秒，默认 3 秒），胶囊会平滑地向上滑出屏幕
- 隐藏状态下，把鼠标移到屏幕顶部灵动岛所在区域，它会自动滑回
- 鼠标悬停、拖动灵动岛、设置窗口打开期间不会触发隐藏
- 隐藏延迟设置为 0 时，鼠标离开后立即开始隐藏

**全屏应用时隐藏**（独立于自动隐藏）：

- 当检测到前台窗口铺满整个显示器（如全屏游戏、全屏视频）时，灵动岛自动隐藏
- 全屏结束时自动恢复显示
- 被全屏隐藏期间，鼠标移到顶部不会再唤出，专注不被打断

**开机自启**：

- 默认关闭；开启后会在 HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run 写入 DynamicIsland 值
- 关闭时会删除该值；v5 不会在未开启时创建任何自启项
- 在设置窗口中切换后需要点"应用/确定"才生效；托盘菜单里的「开机自启动」是立即生效的
- 如果之后移动了 exe 的位置，v5.1 会在下次启动时自动把 Run 键路径刷新为当前 exe 位置（也可以关闭再重新开启一次）

**位置**：

- **左 / 中 / 右**：分别吸附到主显示器工作区的左侧、中央、右侧，距顶部 6 DIP、左右距边缘 12 DIP
- **拖动自定义**：按住灵动岛拖动达到 4 像素以上，位置自动切换为"自定义"，松手即保存；拖动范围限制在当前显示器工作区内
- **重置位置**：设置窗口中的"重置位置"按钮（点应用/确定后生效）或托盘菜单的「重置位置」（立即生效）会清除自定义位置，回到"中"

## ⚙️ 构建与开发

### 🔨 一键构建

```powershell
.\build.ps1
```

构建脚本做的事：

1. 用 vswhere.exe 找到最新的 Visual Studio 安装；
2. 通过 vcvarsall.bat x64 配置 MSVC / Windows SDK 环境；
3. rc.exe 编译 resources/DynamicIsland.rc（图标 + manifest + 版本信息）；
4. cl.exe 以 /O2 /GL /EHsc /std:c++17 /W4 /utf-8（并定义 UNICODE / NOMINMAX）逐文件编译 src/*.cpp，并通过 /external:I 引入 Windows SDK 的 C++/WinRT 头文件（通知监听）；
5. link.exe 以 /LTCG 链接为窗口程序 DynamicIsland.exe，链接 shell32 user32 gdi32 gdiplus ole32 comctl32 dwmapi advapi32 windowsapp runtimeobject；
6. 构建前用 -Clean 可先清理 builds/；若程序正在运行导致 exe 被占用，用 -KillRunning 自动结束旧实例。

### 🧪 单文件编译检查

修改单个模块时，不必完整链接，可用 tools/compile-check.ps1 做快速检查：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\compile-check.ps1 -Files src\time_format.cpp,src\theme.cpp -Tag time
```

输出 COMPILE OK 即通过（/W4 零警告）。目标文件写到 builds\check\<Tag>，多个开发者可以用不同 -Tag 并行检查、互不覆盖。

本键内的设置值都是 REG_DWORD。程序启动时读取，缺失或非法的值会回退到默认值并自动钳制到合法范围；v5.2 新增的 `Notify*` 值缺失时按默认值处理，从 v5.1 升级不需要手动迁移。v5.2.1 把 `NotifyPeekSeconds` 的默认值改为 0（常驻）：从 v5.2.0 升级的安装会保留原来的值（通常是 5），在设置里把停留时长调到 0 或删除该值即可恢复常驻。

### 🚀 开机自启

开启时写入：

```text
HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
    DynamicIsland = "<DynamicIsland.exe 的绝对路径>"
```

关闭时删除该值。v5 遵循"**只在用户开启时才写**"的原则，不会静默创建自启项。

### 🔁 旧版本迁移

从 v4 及更早版本升级时，如果注册表中没有 SettingsVersion（或小于 2），程序会做一次性迁移：

- 旧的 HideDelayMinutes（分钟）与旧的 HideDelaySeconds（0 – 59 秒）会合并为 v5 的 HideDelaySeconds（总秒数）；
- 首次保存后写入 SettingsVersion = 2，并删除 HideDelayMinutes。

### ✍️ 手动编辑

可以用 regedit 查看或修改上述键值，但请**先退出灵动岛**，否则程序退出或下次保存时可能覆盖你的修改。手动改坏了也不必担心：删除 HKCU\SOFTWARE\DynamicIsland 后重启程序即可恢复全部默认值。

## 🛠️ 技术细节

> 更完整的模块、数据流、渲染/动画管线和设计取舍，见 [docs/架构说明.md](docs/架构说明.md)。

- **窗口**：WS_POPUP + WS_EX_LAYERED | WS_EX_TOPMOST | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE，不激活、不进 Alt+Tab
- **渲染**：GDI+ 绘制到 32 位 ARGB 位图 → 预乘 alpha 写入 DIB → UpdateLayeredWindow 整帧提交
- **动画**：归一化进度 + 真实时间步进；悬停 170 ms EaseOutCubic，隐藏 260 ms EaseInOutCubic，副岛弹出 220 ms / 收起 180 ms EaseOutCubic；空闲时不跑动画定时器
- **重绘**：RenderSignature（几何 / 颜色 / 透明度 / 字号 / 文本 / 副岛状态与悬停提示）不变则跳过，静态时没有无效绘制
- **定时器**：内容检查 200 ms 与托盘提示刷新 20 s 常驻；自动隐藏监控 100 ms、动画 tick 16 ms 按需创建；副岛停留检查 250 ms 只在设置了 1–10 秒自动收起时运行（默认常驻时不创建）
- **DPI**：Per-Monitor V2（manifest + 运行时 API），尺寸以 DIP 定义，MulDiv 换算物理像素
- **消息提醒（v5.2）**：两条通道并行——微信走 Windows UI Automation（读取会话列表的无障碍文本），QQ 走 Windows 通知监听（toast）；两者都转换成统一的 AppNotification，投递到 UI 线程后触发圆形副岛；v5.2.1 起副岛默认常驻，点击后收起
- **副岛几何**：圆形副岛直径 = 主胶囊高度，间距 8 DIP，最多两枚；组合总宽 = 主胶囊宽 + 每枚副岛（间距 + 直径）× 自身动画进度，组合左边界按"整体居中"计算，因此出现 / 消失时中点不跳动
- **线程**：UI 线程负责全部窗口与状态；通知监听、微信 UIA 监听各有一个后台工作线程，跨线程只通过 PostMessage 传递堆上的通知数据，UI 线程处理完立即释放

### 📊 性能说明

- 空闲（无悬停、无动画、未启用自动隐藏）：只保留 200 ms 内容检查与 20 s 托盘刷新，几乎不占 CPU；文本与画面签名不变时直接跳过重绘
- 悬停 / 隐藏动画：约 60 FPS 重绘，胶囊面积很小，CPU 占用很低
- 内存：GDI+ 位图只随窗口尺寸变化重建，字体按字号缓存，常驻内存约个位数 MB（以实际任务管理器为准）
- 设置窗口（v5.1 起）脏矩形重绘：悬停 / 点击只重画变化的控件区域，拖动标题栏只移动窗口不重绘，预览只在时间文本变化时重画；v5.2 又把窗口阴影改为只在透明 padding 区域绘制，源码注释记录全窗重绘约从 350 ms 降到 29 ms（150% DPI），列表操作更跟手

## ⚠️ 反作弊系统兼容性说明

### 🎮 游戏兼容性

本程序使用标准的 Windows 桌面 API 实现，**不涉及任何游戏内存修改、进程注入或 API 钩子**；消息提醒也只使用 Windows 公开接口（UI Automation 无障碍读取 + 系统通知），不注入、不挂钩、不读微信 / QQ 进程内存。

#### 技术特性

- ✅ **纯外部进程**：不读取、不修改任何游戏进程内存
- ✅ **标准窗口**：用 CreateWindowEx 创建自己的分层窗口，不做 DirectX / OpenGL / Vulkan 覆盖层
- ✅ **GDI+ 渲染**：绘制自己的窗口位图，不挂钩游戏渲染管线
- ✅ **无进程注入**：不向任何进程注入 DLL 或代码
- ✅ **无全局钩子**：不使用 SetWindowsHookEx 监控键盘鼠标
- ✅ **无网络拦截**：不拦截、不修改任何网络流量
- ✅ **普通用户权限**：asInvoker 运行，不请求管理员权限
- ✅ **可选的全屏隐藏**：检测到全屏前台应用时自动隐藏，减少覆盖层暴露
- ✅ **消息读取方式合规**：微信通过 Windows UI Automation 读取可访问性文本（与读屏软件同类接口），QQ 通过 Windows 通知中心；不注入、不挂钩、不读内存、不访问聊天数据库

#### 已知兼容的反作弊系统

| 反作弊系统 | 情况 | 说明 |
| --- | --- | --- |
| **BattlEye** | ✅ 常规兼容 | 仅作为一个普通置顶窗口存在，不干扰游戏 |
| **Easy Anti-Cheat** | ✅ 常规兼容 | 不注入、不挂钩，通常不会触发检测 |

## 🐛 常见问题与故障排除

### ❓ 看不到灵动岛

1. 检查系统托盘是否有灵动岛图标；有图标说明进程在运行
2. 如果开启了自动隐藏，把鼠标移到屏幕顶部、灵动岛隐藏的位置附近，它会滑回
3. 如果之前拖动过位置，可能停在了屏幕边缘/另一块显示器：托盘菜单 → **重置位置** 回到"中"
4. 检查是否正被"全屏时隐藏"隐藏：切到桌面或关闭全屏应用即可恢复

### ❓ 点击灵动岛打不开设置

- **v5.1 起左键单击灵动岛即可打开设置**；右键单击不再触发任何操作（这是为了避免误触，托盘右键菜单不受影响）
- 如果胶囊被自动隐藏，先把鼠标移到屏幕顶部唤出
- 也可以通过托盘图标左键/双击，或托盘右键菜单 → 设置(灵动岛)... 打开
- 设置窗口是工具窗口，不显示在任务栏；如果被其他窗口挡住，可再次点击托盘图标把它带到前台

### ❓ 收不到微信消息提醒

1. 确认微信 4.x 客户端正在运行（最小化到托盘也可以）；微信完全退出后无法读取会话列表
2. 打开设置 → 通知，确认"消息提醒"和"微信"都已开启（"消息提醒"关闭时微信开关会置灰）
3. 微信提醒读取的是**会话列表的最后一条预览**：正在查看的会话不会提醒，读不到更早的历史消息；预览本身是"图片 / 表情"等摘要时只能显示摘要
4. 如果微信大版本更新后不再提醒，可能是其无障碍（UI Automation）结构发生变化，需要程序适配
5. 隐私模式（关闭"显示内容"）只影响提示文字，不影响是否弹出副岛

### ❓ 收不到 QQ 消息提醒

1. 在 QQ 自己的设置中开启新消息通知（QQNT 的通知设置）
2. Windows"设置 → 通知"中允许 QQ 发送通知
3. 在灵动岛设置 → 通知中确认"消息提醒""QQ"已开启；若卡片显示"未授权通知访问 · 点击授权"，点它并允许
4. QQ 关闭、退出或处于免打扰状态时不会产生 toast，灵动岛也就收不到提醒

### ❓ 副岛提示只有"有新消息" / 没有内容

- 检查是否关闭了"显示内容"（隐私模式只显示"有新消息"）
- 微信只提供会话列表里的预览文本（可能是"图片""[表情]"等摘要）；QQ 的 toast 内容由 QQ 自己决定
- 部分群消息 / 折叠会话的预览可能为空，此时只显示来源

### ❓ 副岛一直显示 / 怎么收起

- **v5.2.1 起副岛默认常驻**，新消息弹出后不会自动消失，这是预期行为；单击副岛（会打开微信 / QQ）、关闭"消息提醒"或关闭对应来源即可收起
- 如果希望它自动收起：设置 → 通知 → 把"停留时长"从"常驻"调到 1–10 秒；悬停时暂停计时，移开后继续
- 副岛显示期间灵动岛不会自动隐藏

### ❓ 时间 / 日期格式和任务栏不一致

灵动岛的日期格式由"日期格式"选项决定，不读取系统区域格式（只有星期名跟随 Windows 区域设置）。改"日期格式"或"显示年份"即可。

### ❓ 开机自启没有生效

1. 确认设置窗口或托盘菜单中的"开机自启"处于开启状态（托盘菜单项带勾）
2. 如果移动过 exe 所在位置，v5.1 会在下次启动时自动刷新 Run 键路径；也可以关闭再重新开启一次
3. 打开 regedit 检查 HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run 是否存在 DynamicIsland 值
4. 某些安全软件会拦截注册表 Run 键写入，请临时放行

### ❓ 设置保存不了 / 重启后恢复默认

1. 检查当前用户是否有 HKCU\SOFTWARE\DynamicIsland 的读写权限（通常都有）
2. 安全软件可能拦截注册表写入
3. 退出程序再修改；程序收到关机/注销消息时也会保存一次

### ❓ 字体太小 / 内容显示不全

- 调大设置里的字号（9 – 32），或换成更大的尺寸（大）
- 内容过长时程序会自动缩小字号避免溢出；如果仍不满意，可减少显示项（关闭年份 / 星期）
- 高 DPI 下不在 100% 缩放时，请确认使用的是 v5 及以上版本（Per-Monitor V2 支持从 v5 开始）

### ❓ 拖动后位置不对 / 跑到副屏

- 拖动位置会被限制在鼠标所在显示器的工作区内；跨屏拖动时注意显示器边界
- 想恢复：设置窗口的"重置位置"，或托盘菜单的「重置位置」

### ❓ 托盘图标消失

Explorer 崩溃或重启后图标可能丢失；v5 会自动监听 TaskbarCreated 广播并重新添加。如果仍未恢复，退出并重新运行程序。

### ❓ 编译失败

1. 确认已安装 Visual Studio 2019/2022，并勾选"使用 C++ 的桌面开发"（含 MSVC x64 和 Windows SDK；通知监听需要 Windows SDK 10.0.17763+ 的 C++/WinRT 头文件）
2. 确认 vswhere.exe 存在（VS 安装程序的一部分）；如未安装 VS 会提示找不到
3. 查看构建输出的第一条错误，常见问题：缺少 Windows SDK、路径含特殊字符、中文源码编码问题（脚本已使用 /utf-8）
4. 只改了一个文件时，可先用 tools\compile-check.ps1 快速定位语法错误

### ❓ 双开时没有第二个窗口

这是**单实例**设计：第二次运行不会启动新进程，而是把已有实例的设置窗口打开（或在被其他窗口挡住时带到前台）。

### ❓ 如何完全卸载

```powershell
.\clean.ps1
```

或手动删除：DynamicIsland.exe、builds/、注册表键 HKCU\SOFTWARE\DynamicIsland、HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run 下的 DynamicIsland 值。

### ❓ 全屏视频 / 游戏时希望隐藏

打开设置 → 行为 → **全屏时隐藏**。它独立于自动隐藏，只在前台窗口铺满显示器时生效。
