# 灵动岛 v5.0.0 架构说明

> 面向开发者的实现说明：模块边界、数据流、渲染与动画管线、持久化方案和关键设计决策。
> 用户使用文档见 [README](../README.md)；最初的项目计划（历史文档）见 [灵动岛实现计划](灵动岛实现计划.md)。

---

## 1. 设计目标与原则

1. **零第三方运行时**：纯 Win32 API + GDI+（Windows 自带），编译为单个 `DynamicIsland.exe`，不依赖 .NET / Electron / Qt。
2. **低存在感**：屏幕顶部的一个小胶囊；不抢焦点（`WS_EX_NOACTIVATE`）、不出现在 Alt+Tab（`WS_EX_TOOLWINDOW`）、不做输入捕获。
3. **状态单一来源**：所有持久化配置集中在 `AppSettings g_settings`（`include/app_state.h`），窗口过程、托盘、设置窗口都只读写这一个结构；磁盘/注册表一致性由 `settings.cpp` 统一负责。
4. **按需重绘**：分层窗口不参与常规 `WM_PAINT` 合成；只有"画面签名"变化或动画推进时才重绘并 `UpdateLayeredWindow`。
5. **单线程**：整个程序只有一个 UI 线程，用窗口定时器驱动时钟检查、托盘提示、自动隐藏与动画（自动隐藏和动画定时器都按需创建，不需要时不占 tick），没有工作线程与锁。
6. **安全边界**：不注入 DLL、不安装钩子、不读写其他进程内存，只创建并绘制自己的置顶窗口。

## 2. 分层与数据流

```text
┌───────────────────────────── Win32 消息循环（main.cpp） ─────────────────────────────┐
│  岛窗口过程 IslandWndProc     │   托盘回调（tray.cpp）   │  设置窗口（settings_dialog.cpp） │
└───────────────┬───────────────┴───────────┬─────────────┴──────────────┬──────────────┘
                │                           │                            │
                ▼                           ▼                            ▼
        交互与命令处理                 托盘菜单 → WM_COMMAND        pending 副本 → Apply
        （悬停 / 拖动 / 点击）          （settings / autostart / …）  Validate → SaveSettings
                │                           │                            │
                └───────────────┬───────────┴────────────────────────────┘
                                ▼
              island.h 应用级命令（实现在 main.cpp）
              ApplySettingsAndRefresh / ResetIslandPosition / RequestApplicationExit
                                │
          ┌─────────────────────┼──────────────────────┬──────────────────────┐
          ▼                     ▼                      ▼                      ▼
   layout（几何 / DPI）   animation（缓动）      rendering（GDI+ 绘制）    theme（调色板）
          │                     │                      │                      │
          └─────────────────────┴──────────┬───────────┴──────────────────────┘
                                           ▼
                              time_format（时间 / 日期文本）
                                           │
                                           ▼
                    per-pixel alpha ARGB 位图 → UpdateLayeredWindow
```

**一次设置变更的完整数据流：**

1. 设置窗口把控件状态写入 `m_pending`（`AppSettings` 的副本），并实时重绘预览卡；
2. 点击"应用/确定"（Apply/OK）：`g_settings = m_pending` → `ValidateSettings()`（全部字段钳制到合法范围）→ `SaveSettings()`（写 HKCU 注册表，并按需增删开机自启 Run 键）；
3. `ApplySettingsAndRefresh()`：`InitIslandLayout()` 重新测量 DPI 与工作区 → `FinishIslandAnimation()` 让动画立刻落到目标状态并强制重绘 → 刷新托盘提示 → 刷新设置窗口；
4. 渲染：`FormatDisplayText(g_settings)` 生成文本 → `ComputeIslandGeometry(hover, hide)` 生成窗口/胶囊矩形 → `GetThemePalette()` 取调色板 → GDI+ 画入 32 位 ARGB 位图 → 预乘 alpha 写入 DIB → `UpdateLayeredWindow`。

## 4. 启动与退出

### 4.1 启动序列

1. `ApplyDpiAwareness()`：优先调用 `SetProcessDpiAwarenessContext(DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2)`，旧系统退回 `SetProcessDPIAware()`；资源中的 manifest 同时声明 `PerMonitorV2`；
2. `CoInitializeEx(COINIT_APARTMENTTHREADED | COINIT_DISABLE_OLE1DDE)`；
3. `CreateMutexW(kIslandMutexName)` 做单实例：若已存在，`FindWindowW(kIslandWindowClass)` 找到已有实例并 `PostMessage(kMsgShowSettings)`，随后退出（第二次启动会直接打开设置窗口）；
4. `GdiplusStartup()`；
5. `LoadSettings()`：读注册表 → 必要时迁移旧版隐藏延迟 → `ValidateSettings()` → 用 `IsAutoStartEnabled()` 校正 `autoStart`（以 Run 键实际存在与否为准）；
6. 注册窗口类 `L"DynamicIslandClass"`，创建 `WS_EX_LAYERED | WS_EX_TOPMOST | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE` 的 `WS_POPUP` 窗口；
7. `InitIslandLayout()` / `InitIslandAnimation()` / `InitIslandRenderer()`；
8. 启动常驻定时器 content（200 ms）与 tray（20 s），按当前设置决定是否创建 autoHide（100 ms）定时器，强制渲染第一帧，`ShowWindow(SW_SHOWNOACTIVATE)`，安装托盘图标；
9. 命令行包含 `--settings` 时 `PostMessage(kMsgShowSettings)`，直接打开设置窗口；
10. 进入 `GetMessage` 消息循环。

### 4.2 退出

托盘菜单「退出」或内部 `RequestApplicationExit()` → `PostMessage(kMsgRequestExit)` → `DestroyWindow()` → `WM_DESTROY`：KillTimer、停止动画、`CloseSettingsDialog(false)`、`DestroyTrayIcon()`、`ShutdownIslandRenderer()`、`PostQuitMessage(0)` → 消息循环结束 → `GdiplusShutdown`、`CoUninitialize`、`CloseHandle(mutex)`。

`WM_ENDSESSION` 为真时先调用 `SaveSettings()`，避免注销/关机丢失刚拖好的位置等设置。

## 6. 渲染管线

### 6.1 窗口形态

- 岛是一个 `WS_EX_LAYERED` 分层窗口，外观完全由 `UpdateLayeredWindow` 的 32 位 ARGB 位图决定；窗口本身不接收 `WM_PAINT` 绘制（`WM_PAINT` 里只 `ValidateRect`）。
- 分层窗口比可见胶囊大一圈，四周留出透明 padding 给投影：左右各 16 DIP、上方 10 DIP、下方 20 DIP（`layout.cpp` 中 kShadow* 常量）。
- 窗口样式 `WS_EX_NOACTIVATE` + `WM_MOUSEACTIVATE` 返回 `MA_NOACTIVATE`：点击/悬停不会抢走当前应用焦点；`WS_EX_TOOLWINDOW` 使其不进入 Alt+Tab。

### 6.2 每帧绘制步骤（`rendering.cpp`）

1. 计算 `IslandGeometry`：窗口矩形 = 胶囊 + 阴影 padding；胶囊大小由当前悬停进度缩放（静止尺寸 × 1.0～1.08），垂直位置由隐藏进度上移；
2. 用 `Graphics::Clear(Color(0,0,0,0))` 清空 ARGB 画布；
3. **软阴影**：绘制 10 层同心圆角矩形，最外层向外扩 8 DIP、向下偏移 5 DIP，透明度由外到内递增（深色主题基准 alpha 11，浅色 8），形成柔和的落地阴影；
4. **胶囊背景**：用垂直 `LinearGradientBrush` 填充圆角矩形，顶/底颜色由主题背景色与黑/白按小比例混合而来，避免纯色平板感；透明度取 `opacity`（55%～100%）；
5. **描边**：1 像素圆角矩形描边（深色主题白、alpha 26；浅色主题黑、alpha 22），让胶囊在相近壁纸色上仍有边界；
6. **文字**：字体像素大小 = `fontSize × dpi/96`，选用 Microsoft YaHei UI（缺失时回退 Segoe UI / Arial），居中绘制；若测量宽/高超出胶囊内可用区域（左右各留 10 DIP，高度留 2 px 余量），逐像素减小字号直到放下（下限 6 px）；
7. **预乘 alpha**：`LockBits` 读出 GDI+ 的非预乘 ARGB，逐像素乘 alpha 后写入 `CreateDIBSection` 的 DIB，满足 `UpdateLayeredWindow` 的 `AC_SRC_ALPHA` 要求；
8. `UpdateLayeredWindow(hwnd, nullptr, &destPoint, &size, memDC, &srcPoint, 0, &blend, ULW_ALPHA)` 一次提交整帧。

### 6.3 优化

- **帧签名缓存**：`RenderSignature` 记录窗口/胶囊矩形、DPI、背景/文字/描边颜色、透明度、字号、粗体、文本内容；`RenderIslandFrame(false)` 在签名不变时直接返回，避免 200 ms 检查定时器造成无意义重绘。设置变更、主题变化等通过 `InvalidateIslandContent()` 强制下一帧重算。
- **表面复用**：位图、`Graphics`、DIB 只在尺寸变化时重建，避免每帧分配。
- **字体缓存**：按"像素字号 + 粗体"缓存 `Gdiplus::Font`，内容变化不会反复创建字体对象。
- **主题只解析一次/帧**：`GetThemePalette()` 返回静态调色板引用，系统主题值被缓存，避免每帧读注册表。

## 7. 动画模型

动画只维护两个归一化进度值（0～1），所有几何都由进度实时推导：

| 进度 | 目标 | 时长 | 缓动 | 效果 |
| --- | --- | --- | --- | --- |
| `hoverProgress` | `SetIslandHoverTarget()` | 170 ms | EaseOutCubic | 胶囊水平居中、向下扩展到 1.08 倍，先快后慢 |
| `hideProgress` | `SetIslandHiddenTarget()` | 260 ms | EaseInOutCubic | 胶囊连同阴影整体滑出工作区上边缘（隐藏距离 = 距工作区顶部距离 + 胶囊高度 + 底部阴影 padding + 4 DIP） |

- `UpdateIslandAnimation()` 在 16 ms 定时器里按**真实经过时间**推进（单帧最多 100 ms，避免睡眠/卡顿后跳变），到达目标值即停掉定时器，空闲时零动画开销；
- 渲染每帧读取 `GetIslandHoverProgress()` / `GetIslandHideProgress()`，所以窗口内容与位置天然同步，不存在两套坐标；
- DPI / 显示设置变化、应用设置时用 `FinishIslandAnimation()` 直接落到目标值并强制重绘，避免残影。

## 8. 布局与 DPI

### 8.1 尺寸常量（DIP，96 DPI 基准）

| 项目 | Small | Medium（默认） | Large |
| --- | --- | --- | --- |
| 胶囊宽 | 120 | 150 | 180 |
| 胶囊高 | 24 | 28 | 32 |

其他布局常量：顶部外边距 6 DIP、左右预设边距 12 DIP、悬停最大放大 1.08、自动隐藏触发区在胶囊外再扩 10 DIP（必要时延伸到工作区顶边）。

### 8.2 DPI 处理

- 进程声明 **Per-Monitor V2**（manifest + 运行时 API 双保险）；
- `InitIslandLayout()` 用 `GetDpiForWindow()`（缺失时退回 `GetDeviceCaps(LOGPIXELSX)`）记录当前 DPI，`ScaleDip()` 通过 `MulDiv(dip, dpi, 96)` 转物理像素；
- `WM_DPICHANGED` / `WM_DISPLAYCHANGE` / `WM_SETTINGCHANGE(SPI_SETWORKAREA)` 时重新初始化布局、把动画落到目标并重绘；
- 预设位置基于**主显示器工作区**计算；自定义位置保存的是物理像素坐标，会按"坐标所在显示器"的工作区钳制。

### 8.3 位置模型

- `IslandPosition`：`LEFT` / `CENTER` / `RIGHT` / `CUSTOM`；
- 拖动达到 4 像素阈值后进入自定义：窗口过程把鼠标位移映射为胶囊左上角，写入 `Position = CUSTOM` 与 `CustomX` / `CustomY`，松开鼠标时 `SaveSettings()`；
- 未拖动（普通左键点击）不会改变位置，松开时打开系统日期时间设置；
- `CustomX/Y` 用哨兵值 `-100000` 表示"未设置"；`ClearCustomPosition()` 恢复 Center 预设。

## 9. 设置与持久化

### 9.1 内存模型

`AppSettings` 是唯一结构（默认值见 `app_state.h`），关键字段：

- 时间/日期：`use24Hour`、`showSeconds`、`showAmPm`、`showDate`、`showYear`、`showWeekday`、`dateFormat`（4 种）；
- 外观：`theme`（Dark/Light/System）、`windowSize`（S/M/L）、`position`、`customX/Y`、`fontSize`（9–32）、`boldFont`、`opacity`（55–100）；
- 行为：`autoHide`、`hideDelaySeconds`（0–3600）、`hideOnFullscreen`、`autoStart`。

### 9.2 读写与迁移

- `LoadSettings()` 打开 `HKCU`\`SOFTWARE\DynamicIsland`，逐项读取并保留默认值；`ValidateSettings()` 把所有字段钳制进合法范围；
- **旧版迁移**：`SettingsVersion < 2` 时，隐藏延迟按 `HideDelayMinutes × 60 + min(HideDelaySeconds, 59)` 换算为 v5 的"总秒数"；保存时写入 `SettingsVersion = 2` 并删除旧的 `HideDelayMinutes`；
- `SaveSettings()` 会先 Validate，然后写全部 DWORD，并同步 Run 键（见下）；
- 开机自启不存 DWORD：`IsAutoStartEnabled()` 直接检查 `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\DynamicIsland` 是否存在；`SetAutoStartEnabled(true)` 写入带引号的 exe 绝对路径，`false` 时删除该值。程序启动时以此实际状态校正 `g_settings.autoStart`，避免"文件被移动后设置显示已开启但实际不生效"。

### 9.3 注册表值总表

完整表格见 README 的"配置存储"一节，要点：

- 位置：`HKEY_CURRENT_USER\SOFTWARE\DynamicIsland`；
- 类型：全部为 `REG_DWORD`（布尔用 0/1，枚举用整数，坐标为物理像素）；
- `SettingsVersion = 2` 为 schema 版本，仅用于迁移判断；
- 开机自启值在 Run 键，类型 `REG_SZ`。

## 10. 主题

`ThemePalette` 同时服务两处 UI，因此包含"岛"与"设置面板"两组颜色（深/浅各一套）：

| 颜色槽 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `islandBackground` | RGB(24,24,28) | RGB(248,248,252) | 胶囊底色 |
| `islandText` | RGB(245,245,250) | RGB(22,22,26) | 时间文字 |
| `islandBorder` | 白 | 黑 | 胶囊描边 |
| `panelBackground` | RGB(28,28,33) | RGB(246,246,250) | 设置窗口背景 |
| `panelSurface` / Hover | RGB(40,40,46) / RGB(52,52,60) | RGB(255,255,255) / RGB(236,236,242) | 卡片与悬停态 |
| `panelText` / Secondary | RGB(240,240,245) / RGB(150,150,160) | RGB(24,24,28) / RGB(110,110,120) | 文字与次要文字 |
| `panelBorder` | RGB(60,60,68) | RGB(220,220,228) | 卡片描边 |
| `accent` / `accentText` | RGB(10,132,255) / 白 | RGB(0,122,255) / 白 | 主按钮、选中态 |

系统主题来自 `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme`（缺失视为浅色）。`IsSystemThemeLight()` 缓存结果，以下时机刷新：

- `WM_THEMECHANGED`；
- `WM_SETTINGCHANGE` 且 `lParam == L"ImmersiveColorSet"`；
- `WM_POWERBROADCAST` 的恢复事件；
- 内容定时器每 25 次（约 5 秒）轮询一次，作为系统不广播消息时的兜底。

## 11. 设置窗口（自绘）

设置窗口与岛一样是 **GDI+ 分层、无原生子控件**的窗口（`L"DynamicIslandSettingsClass"`，`WS_POPUP` + `WS_EX_LAYERED | WS_EX_TOOLWINDOW | WS_EX_TOPMOST`，窗口标题 `Dynamic Island Settings`），所有控件、悬停态和预览都由代码绘制，因此主题、DPI 和圆角外观与岛完全一致。

- **布局**（DIP，按窗口 DPI 缩放；工作区放不下时整体等比缩小，`ComputeDialogScale()` 取 `min(dpi/96, 可用宽高约束)` 并钳制在 0.4–4 之间）：600 × 630 外框（含 18 DIP 透明阴影 padding）；46 DIP 标题栏（标题"灵动岛设置"、副标题 `Dynamic Island v5.0.0`、圆形关闭按钮）；"预览"卡（84 DIP）；左右两列卡片——左列"时钟"（24 小时制、显示秒数、显示上/下午）与"外观"（主题、尺寸、字号、粗体、不透明度），右列"日期"（显示日期/年份/星期 + 4 个显示示例日期的格式胶囊）与"行为"（自动隐藏、隐藏延迟、全屏时隐藏、开机自启、位置与"重置位置"）；底部提示"Enter 确定 · Esc 取消"与"取消 / 应用 / 确定"按钮；
- **数据流**：控件修改 `m_pending`，预览卡调用 `FormatDisplayText(m_pending)` 与 `GetThemePaletteFor(m_pending.theme)` 立刻反映未保存的效果；"应用"或"确定"才执行 `ApplyPending()`：`g_settings = m_pending` → `ValidateSettings` → `SaveSettings` → `ApplySettingsAndRefresh`；
- **交互**：拖动标题栏移动窗口并钳制在工作区内；"取消"/X/Esc 执行 `Close(false)` 丢弃修改；Enter 等同"确定"（应用并关闭）；"重置位置"与"开机自启"在窗口内也只是 pending 修改，随其它设置一起应用；窗口是 modeless 的（`WM_MOUSEACTIVATE` 允许激活以便接收键盘），不阻塞主消息循环，也绝不 `PostQuitMessage`；
- **刷新**：预览卡由 1 秒定时器重绘以更新时间；`RefreshSettingsDialog()` → `ReloadPending()` 在非拖动/非按压状态下从 `g_settings` 重载 pending 并重绘，所以主窗口因系统主题变化而刷新设置窗口时，会以已保存的设置为准；
- **与主窗口协作**：`ApplyPending()` 直接调用 `ApplySettingsAndRefresh()`（同线程），主窗口负责重新布局、重绘岛、刷新托盘提示与设置窗口本身；`kMsgApplySettings` 保留为消息接口。

## 12. 托盘与单实例

- `Shell_NotifyIcon` 使用 `NOTIFYICON_VERSION_4`，图标来自资源 `IDI_APP_ICON`（按 `SM_CXSMICON` 取尺寸，失败时回退 16 px / 系统默认图标）；
- 托盘消息：左键单击/双击 → 打开设置窗口；右键 → `TrackPopupMenuEx` 弹出上下文菜单（默认项为 Settings…）；
- tooltip = `"Dynamic Island — <当前显示文本>"`，每 20 秒刷新一次；
- 监听 `TaskbarCreated` 广播，Explorer 崩溃/重启后自动重新添加图标；
- 单实例由命名互斥体保证；第二个实例不会重复建窗口，只唤醒已有实例打开设置窗口。

## 13. 关键设计决策

| 决策 | 选择 | 理由 / 代价 |
| --- | --- | --- |
| 窗口合成方式 | 分层窗口 + `UpdateLayeredWindow` | 直接得到逐像素 alpha 与抗锯齿圆角/软阴影，不需要 `SetWindowRgn` 的硬边裁剪；代价是每帧要自己做预乘与整窗提交 |
| 绘图库 | GDI+ | Windows 自带、无额外依赖，满足圆角/渐变/文字抗锯齿需求；代价是 CPU 绘制，不如 Direct2D 快，但灵动岛面积很小 |
| 设置界面 | 全自绘窗口 | 原生对话框模板无法跟随深色主题与 Per-Monitor DPI，自绘可复用岛的主题/DPI/圆角体系并获得统一的视觉与实时预览；代价是代码量较大 |
| 配置存储 | HKCU 注册表 | 免安装、无需写配置文件、天然按用户隔离；代价是无法直接当纯文本编辑（可用 regedit） |
| 并发模型 | 单 UI 线程 + 定时器 | 避免线程同步问题，空闲时几乎零开销；代价是耗时操作（如打开控制面板）交给 Shell 异步完成 |
| 重绘策略 | 帧签名缓存 + 按需定时器 | 静态时不做无效绘制，降低 CPU/GPU 占用；代价是需要维护签名比较逻辑 |
| 反作弊策略 | 不规避、纯外部窗口 | 不注入、不挂钩、不读内存，行为透明；同时提供"全屏应用时隐藏"减少覆盖层暴露，但无法承诺任何反作弊系统不误判 |
| 分发方式 | 单 exe，无安装器 | 复制即用；卸载用 `clean.ps1` 清理构建产物、注册表和自启项 |

## 14. 构建与验证

- `build.ps1`：通过 `vswhere.exe` 找到最新 Visual Studio → 调用 `vcvarsall.bat x64` 注入环境 → `rc.exe` 编译资源（图标 + manifest + 版本信息）→ 逐文件 `cl.exe /c /O2 /GL /EHsc /std:c++17 /W4 /utf-8 /DNOMINMAX /DUNICODE /D_UNICODE /Iinclude /Iresources` → `link.exe /SUBSYSTEM:WINDOWS /ENTRY:wWinMainCRTStartup /OPT:REF /OPT:ICF /LTCG` 链接 `shell32 user32 gdi32 gdiplus ole32 comctl32 dwmapi advapi32` → 输出 `DynamicIsland.exe`；支持 `-Clean`（先清理 `builds/`）与 `-KillRunning`（链接前结束正在运行的实例）；
- `tools/compile-check.ps1`：同样的 MSVC 环境，对一个或多个源文件只编译不链接，目标文件写到 `builds/check/<Tag>`，可多标签并行；成功时打印 `COMPILE OK`。用于改单个模块时的快速语法/语义检查；
- 资源文件：`resources/app.ico`（多尺寸图标）、`resources/app.manifest`（Per-Monitor V2、asInvoker、Win10/11 兼容性）、`resources/DynamicIsland.rc`（图标 + RT_MANIFEST + VERSIONINFO 5.0.0.0）；
- 代码规范：头文件只放接口与常量（大量使用 `constexpr`），实现放 `.cpp` 的匿名 namespace 中；/W4 零警告；所有 GDI/GDI+ 对象在退出路径上有对应释放。

## 15. 已知限制与可扩展点

- 预设位置始终基于主显示器；多显示器下想让胶囊出现在副屏顶部，需要拖动成自定义位置（会按该显示器工作区钳制）；
- 自定义位置保存的是物理像素，DPI 变化后胶囊会重新缩放但仍按原像素坐标钳制，不会相对原位置等比移动；
- 界面文案均为中文（设置窗口、关于对话框、托盘菜单），未做多语言切换；
- 托盘 tooltip 每 20 秒刷新一次，因此 tooltip 中的时间最多可能滞后 20 秒；
- 主题轮询兜底为 5 秒一次，极端环境下切换主题可能有最多 5 秒延迟；
- 全屏检测基于前台窗口矩形是否覆盖显示器，个别无边框窗口化/多屏拉伸场景可能误判；
- 无自动更新、无代码签名；反作弊兼容性只做行为声明，不作保证。
